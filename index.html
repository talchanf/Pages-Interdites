Les données sont fortement orientées vers les sources anglophones : les États-Unis apparaissent beaucoup parce que les interdictions y sont systématiquement recensées (PEN America, ALA), alors que la censure en Chine, en Russie ou en Iran est bien plus fréquente que ce que montrent les chiffres.

À propos

Pages Interdites recense des livres interdits, restreints ou contestés à travers le monde. Chaque fiche liste les mesures de censure connues avec le pays, l'année, la portée (école, gouvernement, bibliothèque…), le statut, les motifs invoqués et la source.

Données : Banned Books, Open Censorship Core, Ludo Raedts / banned-books.org, version du 10/11/2026, licence CC-BY-4.0, DOI 10.5281/zenodo.24109205. Les titres sont ceux du jeu de données (souvent en anglais) ; une grande partie des sources n'est pas encore vérifiée par ses auteurs.

Mettre à jour les données

Quand une nouvelle version paraît sur Zenodo, dépose ici le fichier banned-books-open-core.zip (ou ses fichiers CSV : books, authors, bans, ban_reasons, ban_sources, countries). Un fichier CSV ou JSON plat avec des colonnes title, author, country, year, reason est aussi accepté.

L'import ne modifie que ton affichage, dans ton navigateur. Pour mettre à jour le site pour tout le monde, il faut le republier avec les nouvelles données.
